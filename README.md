# ReachFive Identity Web Core SDK

## Installation

The following command installs the Identity Web Core SDK as a Node.js dependency:

```sh
npm install --save @reachfive/identity-core
```

## Documentation

You'll find the documentation of the methods exposed [here](https://developer.reachfive.com/sdk-core/index.html).

## QA playground

The ReachFive team tests the SDK with a QA playground, kept in the internal repository
[ReachFive/identity-web-core-playground](https://github.com/ReachFive/identity-web-core-playground). It loads any
published version of the SDK. To try a branch before it is published, build it (`npm run build`) and point a local
playground at this checkout with `PLAYGROUND_SDK_DIR` (see the playground's README).
